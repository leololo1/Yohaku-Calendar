# Yohaku Calendar Component Rules

## Floating Add Button

Use a small white circular button with a soft shadow.

Size:

```text
48-56pt
```

Style:

- white fill
- subtle shadow
- thin plus icon
- no strong accent color

The plus button should be small and quiet.

---

## Icon Buttons

Use thin line icons only.

Icon color:

```text
#777777
```

Icon stroke should be thin.

Avoid filled icons.

---

## Calendar Date Cells

The calendar grid must be very light.

Rules:

- No thick borders
- No boxed dates
- No strong background blocks
- Selected date may use a soft pale gray circle
- Event indicator may be a tiny gray dot
- Dates from other months should be very light

Selected date background:

```text
#EFEFED
```

Event dot:

```text
#8E8E89
```

---

## Schedule Rows

Each schedule row should include:

- Start time
- End time if needed
- Schedule title

Rows should be separated by very subtle dividers.

Do not use colored cards.
Do not use category colors.
Do not use icons for every schedule.

The list should feel like text placed on paper.

---

## Event Blocks

Event blocks must be very pale.

Event block background:

```text
#F4F4F2
```

Event block text:

```text
#333333
```

Rules:

- Event blocks should have soft corners
- Lines must be extremely subtle
- Do not use strong colored blocks

---

## Forms

Event forms should feel like writing on blank paper.

Avoid complex forms.

Do not show too many controls at once.

---

## Detail Rows

Use icons only if they are very thin and minimal.

Text-only layout is preferred.

If a field is empty, hide it instead of showing placeholder noise.
