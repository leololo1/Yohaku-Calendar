# Yohaku Calendar Design Philosophy

Yohaku Calendar is a quiet, minimal calendar app.

The app must feel like a blank white space where only necessary schedules are placed gently.

Do not design for maximum usability. Design for stillness, clarity, restraint, and visual beauty.

The app should feel:

- white
- quiet
- spacious
- refined
- calm
- almost empty
- intentionally minimal

The core principle is:

> Remove anything that does not need to exist.

Yohaku Calendar is not a colorful productivity app.
It is not a busy schedule manager.
It is not a dashboard.

It is a white calendar for people who love silence, margin, and simplicity.

---

## Design Decision Rule

When adding any UI element, ask:

1. Is this necessary for registering or viewing a schedule?
2. Can the user understand the screen without this?
3. Does this reduce the feeling of white space?
4. Does this make the app feel like a normal busy calendar app?
5. Would removing it make the design more Yohaku?

If the element is not necessary, remove it.

If there is a conflict between usability and visual restraint, prefer visual restraint unless the app becomes unusable.

## Final Direction

Yohaku Calendar should feel like:

- a blank page
- a quiet room
- a white notebook
- a high-end paper calendar
- a calm place to place future events

It should not feel like:

- Google Calendar
- a productivity dashboard
- a colorful schedule manager
- a task app
- a business tool

The goal is not to manage everything.

The goal is to place only what matters.
